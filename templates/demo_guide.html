Ten-minute judging path

Start as Demo as Brand (NovaFrame). Keep this page in a tab. Nothing here is a popup.

  1. Discover a creator — open Find Creators.
  2. Filter by AI skills/tools — Runway + AI Filmmaker.
  3. Open Aria Chen, then a portfolio piece such as Helix Night Atelier.
  4. Hover verification badges (Profile → Trusted). Read the tooltip copy.
  5. Create an AI-assisted brief using “I need a futuristic product launch video for an AI startup.”
  6. On the published brief, read AI Match % and the why-text.
  7. Shortlist via Save on a recommended creator.
  8. Connect / message — NovaFrame already has threads with Aria and Marcus.
  9. Hire from Aria’s profile or accept Kenji’s application (Lumina cabin is already in Production).
  10. Track project stages Discovery → Completed.
